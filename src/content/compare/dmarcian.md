dmarcian helped create this category — it was co-founded by an author of the
DMARC specification — and it's a capable, well-supported hosted platform. It is
**cloud-only**, though, priced by **domains and message volume**, and your
report data lives in dmarcian's cloud. DMARC Analyzer is open source and
self-hosted: unlimited domains at no per-domain cost, with reports that never
leave your infrastructure.

## Side by side

| | DMARC Analyzer | dmarcian |
|---|---|---|
| Hosting | Self-hosted | Cloud SaaS |
| Open source | Yes (Apache-2.0) | No |
| Pricing model | Free; unlimited domains | Tiered by domains + message volume |
| Your report data | Stays on your infrastructure | Stored in the vendor's cloud |
| Agencies / many clients | Yes, self-hosted multi-tenant | Yes (paid) |
| Getting started | Docker on your server | SaaS signup |

## Where dmarcian fits

If you want a fully managed service with vendor support and don't need to
self-host, dmarcian is a mature, credible option.

## Where DMARC Analyzer fits

If you care about **data sovereignty**, want **no per-domain cost at scale**, or
value **open source you can audit and run yourself**, DMARC Analyzer is built for
exactly that. New to DMARC? Start by
[publishing your first record](/guides/publish-your-first-dmarc-record) and
[reading the reports](/guides/how-to-read-a-dmarc-aggregate-report).
